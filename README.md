# socialmedia — starter website

## Included
- Responsive social feed and sample Reels screen
- Demo sign-up/login form (local browser session only)
- Create text/gradient demo posts
- Like, comment, follow suggestions
- Local demo chat
- Brand collaboration sample briefs and a pitch generator
- Local browser persistence via localStorage

## Run
Open `index.html` in a modern browser, or serve this folder with any static web server.

## Important limitations
This is a front-end prototype, not a production Instagram clone. Demo accounts are not secure, and data is stored only in the current browser. Live video, actual video uploads, cross-user chat, real profiles/followers, moderation, notifications, brand campaign delivery and monetization need a backend, secure authentication, database, file/video storage, and deployment. The brand opportunities are examples only; they are not live offers. No application is sent to real brands.

## Suggested free-first roadmap
1. Test the prototype and choose branding.
2. Add backend auth and database (e.g. Supabase free tier, subject to current limits).
3. Add image/video storage and upload rules.
4. Add real-time chat with per-user authorization.
5. Add live video using a suitable streaming provider; live streaming may incur costs.
6. Add reporting/blocking, moderation, privacy policy and terms before public launch.
7. Add brand campaign management, creator metrics, payouts and disclosure tools.
